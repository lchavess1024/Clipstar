Have a privacy concern?

Clipstar is local by design: no account, telemetry, analytics, or external server. Clips are stored in Chrome on this device. Clipstar receives temporary page access only after you choose it from a text field’s right-click menu.

Review Clipstar’s source code on GitHub or report a privacy concern. Please don’t include clip contents or other sensitive information in a public report.
